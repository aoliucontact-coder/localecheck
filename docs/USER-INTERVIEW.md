# 首轮用户访谈提纲

目标：找到已有中文产品、即将上线或维护英文版本的 3—5 位开发者。每次约 20 分钟，先了解经历再展示产品。参与与记录须征得对方同意。

1. 最近一次更新英文文案是什么时候？请描述从中文稿到上线的步骤。
2. 谁翻译、谁检查？用什么工具和文件格式？
3. 最近发现过什么具体错误？怎么发现，造成了什么影响？
4. 哪一步最花时间？能否看一份可公开或脱敏的材料？
5. 术语如何统一？遇到上下文缺失时怎么办？
6. 请用示例完成一次导入、检查、确认、导出，观察卡住的位置，避免提示操作。
7. 哪条提示有帮助，哪条不应该出现？为什么？
8. 如果加入你的实际流程，你会在什么时候用？有什么条件尚未满足？

记录：用户角色、现有流程、原话、观察事实、需求假设、待验证问题。不要把礼貌性赞同当作需求验证。
