## 4. 可用性问题排序

严重程度定义：

- `阻断`：无法完成导入、检查、确认或导出；
- `严重`：可能造成错误译文、数据丢失或隐私误解；
- `一般`：可以完成任务，但明显增加时间或困惑；
- `轻微`：不影响任务完成。

| 问题 | 严重程度 | 影响用户数 | 证据编号 | 修复建议 | 优先级 |
| --- | --- | ---: | --- | --- | --- |
|  |  | 0 |  |  | 待定 |

排序规则：先处理阻断问题，再处理数据或判断风险，然后处理至少两位用户共同遇到的问题。
